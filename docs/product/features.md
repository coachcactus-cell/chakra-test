# 脉轮测试网站

## 产品概述
一个繁体中文的脉轮能量测试网站，用户回答 56 道问题后，获得七个脉轮的能量状态分析报告。

## 核心功能

### 1. 首页介绍
- 网站标题与脉轮简介
- 测试说明（56 题，6 级评分）
- 开始测试按钮
- 七脉轮图示

### 2. 问卷页面
- 56 道问题，每题 6 级评分（完全没有 / 轻微 / 中等偏弱 / 中等偏强 / 强烈 / 感觉强烈）
- 进度条显示答题进度
- 提交按钮（需答完所有题目）

### 3. 结果页面
- 七个脉轮的能量柱状图
- 每个脉轮的状态：不活跃 / 适度活跃 / 过度活跃
- 各脉轮简短说明与建议
- 重新测试按钮

## 数据结构

### 56 道题目（繁体中文）
每题对应一个脉轮（7 脉轮 × 8 题）
